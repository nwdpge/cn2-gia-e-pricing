## CN2 GIA-E 到底是什么，为什么要为它多花钱

CN2 GIA 是中国电信 AS4809 骨干网里的高端档位，走电信的国际专用通道，全程 CN2，电信、联通、移动三网回程都有保障。搬瓦工官方对这条线的评价是「多年来我们观察到这条线路问题最少、非常稳定」，但同时也承认两个缺点：贵（IP transit 报价能到 $120/Mbps，1Gbps 满带宽一个月账单是十万美元量级）和容量有限，遇到 DDoS 攻击时只能临时屏蔽 IP。

对比之下，普通 163 线路（AS4134）晚高峰丢包率可能超过 30%，官方原话是这种丢包下「几乎不可能稳定地为中国访客提供网页内容、开视频会议、托管网游或者连接国内办公室」。CN2 GIA-E 的专用通道在社区实测中长期丢包率低于 0.1%，晚高峰平均延迟约 158ms。这个差距在实际使用里就是「晚上八点视频会议卡不卡」的区别。

GIA-E 里的「E」代表 ECommerce（电商级线路），核心机房是洛杉矶 DC6（USCA_6），官方介绍页对 DC9（USCA_9）的描述是「提供最佳的整体网络容量和稳定性」。DC6 在 CN2 GIA 基础上叠加了移动 CMIN2（AS58807）和联通 China Unicom Premium（AS10099），是搬瓦工洛杉矶线路最丰富的机房。一条 DC6 机房有 8 条 10G CN2 GIA/CTGNet 上联。

一句话概括它和香港 CN2 GIA（Ultra 系列）的关系：线路规格接近，价格大约只有一半，代价是服务器在美国，跨太平洋多一跳延迟。
